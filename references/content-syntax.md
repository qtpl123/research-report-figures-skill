# content.md 语法参考

## 文件头（front matter）

```
---
title: 报告标题
subtitle: 副标题（可选）
author: 编制（可选）
date: 2026-10-09
version: v1.0（可选）
---
```

标题块之后会自动分页，形成封面。

## 标题与正文

```
# 1 一级标题
## 1.1 二级标题
### 1.1.1 三级标题

普通段落。支持 **加粗**、`等宽`、[链接文字](https://example.com)。

> 引用/提示段落，渲染为左侧竖线的强调块。

- 无序列表项
1. 有序列表项
```

一级到三级标题会进入目录（`[[TOC]]` 生成的目录域）。

## 目录

在正文开始处写一行 `[[TOC]]`，装配时插入 Word 目录域并设置“打开文档时更新域”。

## 插图

```
:::figure fig-01
caption: 图题（可省略，省略时使用 manifest 里的 title）
source: 依据 XXX 公开资料整理
note: 本图为技术示意图，非真实照片
:::
```

`source` 和 `note` 会合并成图注下方的一行小字。图片文件、类型、来源、许可都从 `assets/manifest.json` 读取。

## 插表

表题在表格上方，`[[表:tab-01]]` 可在正文引用表号。

```
:::table tab-01
caption: 主要层析技术对比
:::
| 技术 | 分离原理 | 适用阶段 |
| --- | --- | --- |
| 亲和层析 | 生物特异性识别 | 捕获 |
:::end
```

也可以直接写 Markdown 管道表格（不编号、不显示表题）。

## 交叉引用

- `[[图:fig-01]]` → 渲染为“图 1”
- `[[表:tab-01]]` → 渲染为“表 1”

编号按图/表在正文中出现的顺序自动分配，插入或删除图后无需手工改号。

## 参考文献

建议单列一节，逐条写出标题、来源与可点击链接：

```
# 8 参考文献

1. 机构. 文件名. [链接文字](https://example.com)
```

真实图片来源（维基共享资源等）也要写进参考文献，与 manifest.json 中的记录对应。
